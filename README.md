## Projetos em destaque

### Zenit / Levitta — Sistema de gestão e portal imobiliário

**ASP.NET Core · EF Core · PostgreSQL · Docker · Cloudflare R2 · React · Next.js**

Plataforma com sistema de gestão imobiliária e portal público para consulta de imóveis e empreendimentos. Inclui funcionalidades de cadastro, organização e publicação de anúncios, gestão de mídias e regras de visibilidade dos imóveis.

Atuo no desenvolvimento do backend, na implementação de regras de negócio e integrações, no fluxo de upload de imagens e na implantação dos serviços em ambiente Linux com Docker.

**[Conhecer o portal Levitta](https://levittaimoveis.com.br/)**
